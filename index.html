Help & User Guide

This tool is shared by the whole office using the same office login as the other Camp Office systems — everything is saved online immediately and everyone sees the same roster.

How do I build this week's roster?
Pick the Monday it starts from under "Week Starting", then click "Build This Week's Grid" to create an empty grid you can fill in.
How does "Import from Cause List PDF" work?
Upload the week's Cause List PDF one bench/court at a time — the roster fills itself in automatically. Always check the report shown afterwards and fix anything it flags before relying on the result.
What are "Saved Rosters" for?
Click "📁 Saved Rosters" to see and reopen every week you've built before, so you never lose an old roster.
How do I switch language or theme?
Use the اردو/English button to switch language, and the 🎨 button to pick from 7 color themes — both apply instantly on your own screen.
Where is my data stored — is it safe if this computer breaks?
Everything is saved online in this system's shared database, not on any one computer, so nothing is lost if this computer is lost or damaged.
Can more than one person use it at the same time?
Yes — everyone signed in sees the same live roster, and a change made by one person appears for everyone else within a moment.
How do I print or download this roster as a PDF?
Use the Print button for a clean printable page, or the "Download PDF" button right next to it — it builds and downloads a ready PDF file directly, with no print window and no browser header/footer added to it.
I forgot my password — what should I do?
Click "Forgot password?" on the sign-in screen, enter your email, and a password reset link will be sent to your inbox (check spam too) — no need to contact an Administrator.
Who can see this roster — is it private to our office?
Only people signed in with the shared office login used across the Camp Office systems can see it, and access is further enforced by the database's own security rules.
Note: Upload the week's Cause List PDF below and the roster builds itself — Bench, Day, Sr.No., Case Type/No./Year and Nature code are all read straight from the PDF for the Benches this office tracks (III, IV, VI, VII). Anything the parser can't confidently read, or that belongs to a Bench this office doesn't track, is left out and listed in the report so it can be checked/added by hand. Always compare the built roster against the PDF once before printing.
