Pick a register above, then add, rename, edit (dropdown options), or delete custom data-entry fields for it. Built-in fields (Date, Bill No, Gross, Tax, etc.) cannot be removed here, since the whole system's calculations depend on them — only fields you add yourself through this page can be changed or deleted. Ledger & Budget works a little differently: it has no add/edit entry form (its rows are the 41 fixed Contingent Heads), so a custom field there shows up as one more click-to-edit column against each head, the same way Final Budget and Prior Expenditure already work. Attendance Register (a day-by-day grid, not a per-record form) still can't take custom fields the same way, since it has no per-record value to attach one to.
