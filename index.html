Help & User Guide

This system is shared by the whole office — everything you enter is saved online immediately and every other signed-in user sees the same information. Only an Administrator can add, edit, or delete a case; a Guest can view, search, and print everything.

Add a Case

  1. Fill in the Case No, Title of Case, Vs No, and Case Type (BBA / BAA / COB).
  2. Add the F.I.R. No and date (or just the year if the exact date isn't known), Police Station, District and Tehsil — type a new one if it isn't already in the list.
  3. Pick the Bench No and Case Fixed Date, then choose the Cause List Serial No — available serials only appear after the bench and date are set.
  4. Click "Save case" to add it to the register below.

Notice Sender Details

  1. Fill in your Name, Designation, Mobile No and Office Phone once — this appears as the sender on every notice you print.
  2. Update it any time your designation or contact number changes; it applies to every notice printed after that.

Search, Print and the Register

  1. Use "Search & filter cases" to narrow the list by Case No, Case Type, District, Bench No, Serial No, or a fixed-date range.
  2. In the results table, click a row's print icon/button to generate that case's printable notice — choose paper size and language there, then Print.
  3. An Administrator can Edit or Delete any row; a Guest can only view and print.

Report

  1. The Report card summarises cases by Bench, using whatever filters are currently set above it.
  2. Set a fixed-date range in Search & filter first if you want the report for a specific period.
  3. Use "Export list (Excel)" or "Print list & summary" to share or file a copy.

Backup, Restore & Access

  1. Data is saved online immediately, shared by everyone signed in — use "Backup (save file)" occasionally as an extra copy.
  2. "Restore from file" replaces all shared data with a backup file — Administrators only, since it affects everyone.
  3. New accounts start as "Guest" (view-only); an existing Administrator must promote them from the Firebase console's user records.

Frequently asked questions

I signed up but I can't add, edit, or delete a case — why?
New accounts start as "Guest" (view-only) for safety. An existing Administrator needs to change your role before you can add, edit, or delete anything.
How do I switch between English and Urdu?
Use the language dropdown at the top-right of the page for the whole system, or the separate language dropdown inside the notice print window for just that notice.
The Police Station / District / Tehsil I need isn't in the list — what do I do?
Choose "Type a new one" (or the equivalent option) from that dropdown and type it in — it's saved and will appear in the list from then on.
Where is my data stored — is it safe if this computer breaks?
Everything is saved online in this system's shared database, not just on this computer, so it stays safe even if this computer is lost or damaged. It's still good practice to use "Backup (save file)" now and then as an extra copy.
Can more than one person use the system at the same time?
Yes — everyone signed in sees the same shared data. If two people save at almost the same moment, both changes are kept safely.
What does the Cause List Serial No actually mean?
It's the case's position on that bench's cause list for the fixed date you chose — pick the bench and date first, and only the serial numbers available for that day will show up.
How do I print a notice?
Open the case from the results table — a print-ready notice appears where you can pick paper size and language, then click Print.
Can I get this data into Excel?
Yes — the Report card has an "Export list (Excel)" button so you can open the data directly in Excel.
I forgot my password — what should I do?
This system doesn't yet have an automatic "forgot password" option. Please contact an Administrator for help.
Who can see this data — is it private to our office?
Only people who sign in with an account on this system can see it. Access is controlled by the Administrator/Guest roles, and further enforced by the database's own security rules.
